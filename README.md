# 상수와 변수 (Routine & Surrender)

개인 저널링(기록) 앱입니다. 매일 반복하기로 정한 **상수(루틴)**와, 그날 예측하지 못하게 일어난 **변수(사건)**를 나눠서 적는 하루 기록장이에요.

**사용 링크**: https://leekangeun0120.github.io/routine-and-surrender/

## 무엇을 할 수 있나요

- **상수노트**: 매일 반복할 루틴 체크리스트, 오늘의 목표(돈/일/관계/건강/행복), 외운 문장, 공부한 것, 감사한 것 등을 기록
- **변수노트**: 그날 있었던 예측 못한 상황을 상황/감정/행동/결과/깨달은 점/받아들임 여부로 기록
- **달력**: 날짜별로 상수·변수를 기록했는지 한눈에 보기
- **백업**: 기록 전체를 JSON 파일로 내보내기/불러오기
- **홈 화면 설치**: 아이폰(Safari)·안드로이드(Chrome)에서 앱처럼 홈 화면에 추가 가능

## 어떻게 만들어졌나요

- **구성**: HTML + CSS + 순수 JavaScript로 작성된 파일 하나(`index.html`)뿐입니다. 별도 빌드 과정이나 프레임워크가 없어요.
- **저장 방식**: 서버나 데이터베이스가 없습니다. 모든 기록은 그 기록을 남긴 사람의 **브라우저(localStorage)**에만 저장돼요. 그래서:
  - 사용자가 몇 명이든 서로의 기록이 섞이지 않음
  - 대신 같은 사람이라도 폰/PC를 오가며 자동으로 이어지지는 않음 (수동 백업 파일로만 이전 가능)
- **호스팅**: [GitHub Pages](https://pages.github.com/)로 무료 배포. 정적 파일을 그대로 서빙하는 방식이라 서버 관리가 필요 없고, 트래픽이 늘어도 안정적이에요.
- **제작 도구**: Claude Code로 작성. 원래는 Claude 아티팩트(claude.ai) 안에서 만들었다가, 안드로이드에서 커스텀 앱 아이콘이 적용되지 않는 문제와 미리보기 틀 안에서 화면 비율이 깨지는 문제를 해결하기 위해 이 저장소로 독립시켰어요.

## 코드 구조 (`index.html` 한 파일 안에서)

- `<style>`: 라이트/다크 테마 대응 CSS (`prefers-color-scheme` + 수동 토글)
- `<div class="wrap">`: 사용법 안내, 날짜 이동, 백업 버튼, 달력, 상수/변수 공식, 상수노트·변수노트 패널
- `<script>`: 아래 역할을 하는 순수 JS
  - `Storage` 객체: `localStorage` 기반 저장/조회 (날짜별 문서, 루틴 목록)
  - 달력 렌더링, 날짜 이동, 자동 저장(디바운스)
  - 백업 JSON 내보내기/불러오기
  - (참고) `window.claude.use(...)` 관련 코드는 claude.ai 아티팩트 환경에서만 동작하는 부분이라, 이 GitHub Pages 버전에서는 자동으로 꺼지고 항상 localStorage로만 동작합니다.

## 로컬에서 직접 열어보기

이 저장소를 내려받아 `index.html`을 브라우저로 더블클릭해서 열면 바로 실행됩니다(별도 서버 설치 불필요).

## 업데이트하기

`index.html`을 수정한 뒤 `main`(또는 `master`) 브랜치에 push하면, GitHub Pages가 1~2분 안에 자동으로 새 버전을 반영합니다. 저장 키(localStorage 이름)나 데이터 구조를 크게 바꾸지 않는 한, 기존 사용자들의 기록은 그대로 유지됩니다.
